## Final Scope

EventHub is a frontend event management application built with React and Vite.

The project intentionally remains **frontend-only**. No backend, database, authentication system, or external API is required for the current scope.

The goal of the project is to demonstrate practical frontend development skills through a complete and interactive event management interface.

## Important Scope Decisions

The following decisions were made intentionally to keep the project aligned with its purpose and the developer's current frontend specialization:

- Registration remains available as a **frontend interaction**.
- Event creation remains available through the existing frontend form.
- Favorites are handled on the client side.
- No backend was added.
- No database was added.
- No authentication system was added.
- No unnecessary external libraries or advanced architecture were introduced.
- Existing project features were preserved wherever possible instead of replacing the project with a new implementation.
